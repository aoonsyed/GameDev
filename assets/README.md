# Assets

Visuals are drawn and sound effects synthesised in code; only fonts ship as files.

- `fonts/display.ttf` — Orbitron (titles, buttons), SIL Open Font License: `fonts/OFL-Orbitron.txt`
- `fonts/body.ttf` — Exo 2 (body text, numbers), SIL Open Font License: `fonts/OFL-Exo2.txt`
- `sounds/` — optional `.ogg` effects from jsfxr or Freesound (CC0).

Only add assets you are allowed to redistribute (CC0 / OFL).
